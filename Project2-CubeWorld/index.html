How image sampling works

Each terrain grid cell samples one pixel from the color image and one pixel from the height map. The color image's RGB values are divided by 255 to create WebGL color values between 0 and 1. The height map's grayscale brightness is converted into a height between 0.35 and the selected maximum height plus 0.35. The sampled values are stored in instance buffers and rendered using one instanced draw call.
